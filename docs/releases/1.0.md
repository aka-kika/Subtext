## What it is

<!-- SF Symbol: app -->
A floating, keyboard-first macOS panel for the system text replacements you
already own — summon, filter, copy, gone. Distinct because it adds zero new
snippet infrastructure: it is a fast face for what System Settings buries.

Built by **KIKA** ([akakika.com](https://akakika.com)). Part of the daily toolkit
it was built to serve.

## The milestone

<!-- SF Symbol: flag.checkered -->
First public release — and the whole life of the app so far happened in one
day: built in the morning, debugged and hardened in the evening, signed,
notarized, and published the same night. A user can now grab any of their
text replacements from anywhere with three keystrokes instead of a trip
into System Settings.

## What shipped in 1.0

<!-- SF Symbol: shippingbox -->
- **Floating panel** — non-activating overlay; type to filter, arrows to
  navigate, Enter to copy, Escape to dismiss.
- **Live system reads** — the replacement list is re-read on every panel
  open, so additions from anywhere appear without a relaunch.
- **Global hotkey recorder** — any combo, recorded in Settings.
- **Import / remove** — `.plist` import from System Settings; removal by
  shortcut.
- **Sizes, themes, login item** — Mini / Normal / Big, Dark / Light /
  System, launch at login, optional menu bar item.

## The story (how 1.0 came together)

<!-- SF Symbol: book.closed -->
- Born from a menu-bar allergy: the SEEDling seeding workflow needed a
  fill-the-blanks prompt one keystroke away, and the system's text
  replacements were the right home for it — if only they were reachable.
- The day-one build read the replacement list once at launch. Live testing
  exposed two layered bugs: every panel entry point bypassed the reload
  path entirely, and even with that fixed, UserDefaults caches the global
  domain per-process. CFPreferences with an explicit synchronize fixed it
  for good — and fixed the "Reload from system" button along the way.
- The release pipeline surfaced its own snags: universal builds fail on
  the macOS 27 SDK (x86_64 deprecated), and duplicate Developer ID certs
  make name-based signing ambiguous. The script now builds arm64 and signs
  by certificate hash.
- The final stretch: About tab with project links, README front door,
  MIT license, changelog, and the repo flipped public — all inside the
  same day it was born.
